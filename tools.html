Health Tools

Interactive health-awareness demonstrations

These simple browser-based tools demonstrate how JavaScript and localStorage can be used in a student web project.

📈

Daily Health Score

Enter today's basic activity information to calculate a simple educational score.

Educational project demonstration only — this score is not a medical assessment and should not be used to diagnose or treat any condition.
💊

Medicine Reminder

Save simple medicine-name and time reminders in this browser.

Reminder data is stored only in this browser using localStorage. It does not send notifications or replace medical advice.
